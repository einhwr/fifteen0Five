KOPI KITA - WEBSITE TOKO KOPI SEDERHANA

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder kopi-kita menggunakan Visual Studio Code.
3. Buka file index.html di browser. Bisa juga menggunakan ekstensi Live Server di VS Code.

STRUKTUR FOLDER
- index.html       : struktur halaman
- css/style.css    : desain dan tampilan
- js/script.js     : daftar produk dan fungsi keranjang

YANG PERLU DIUBAH
1. Buka js/script.js.
2. Ganti whatsappNumber = "6281234567890" dengan nomor WhatsApp toko.
   Gunakan format 62, tanpa tanda +, spasi, atau angka 0 di depan.
3. Ubah nama, deskripsi, harga, dan gambar produk pada array products.
4. Buka index.html untuk mengubah nama toko dan teks halaman.

CATATAN
- Website ini adalah frontend statis. Keranjang berjalan di browser.
- Pesanan dikirim ke WhatsApp, belum tersimpan di database.
- Foto produk menggunakan URL gambar online sehingga perlu koneksi internet.
